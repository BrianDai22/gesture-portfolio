# Roadmap: Gesture-Controlled Portfolio

## Overview

Build a camera-based, gesture-controlled portfolio website in 4 phases: set up the project foundation with dev tooling and CDN imports, implement core hand tracking and 3D scene interaction, add all portfolio content with polished UI, then test and deploy to AWS.

## Phases

- [ ] **Phase 1: Foundation** - Project setup, dev server, HTML/CSS scaffold, CDN imports
- [ ] **Phase 2: Core Interaction** - Camera access, MediaPipe hand tracking, Three.js 3D scene, gesture navigation
- [ ] **Phase 3: Content & UI** - Portfolio sections, resume download, gesture tutorial, styling
- [ ] **Phase 4: Polish & Deploy** - Final testing, polish, AWS S3 + CloudFront deployment

## Phase Details

### Phase 1: Foundation
**Goal**: Working project skeleton with dev server and all dependencies loaded
**Depends on**: Nothing (first phase)
**Plans**: 3 plans

Plans:
- [ ] 01-01: GitHub repo creation, project structure, initial commit (verify git workflow)
- [ ] 01-02: Dev server setup (package.json, live-server, npm scripts)
- [ ] 01-03: HTML scaffold, CSS base styles, CDN imports (Three.js, MediaPipe), JS entry point

### Phase 2: Core Interaction
**Goal**: Hand gestures detected and mapped to 3D scene navigation
**Depends on**: Phase 1
**Plans**: 3 plans

Plans:
- [ ] 02-01: Camera access, video feed display, MediaPipe Hands initialization
- [ ] 02-02: Gesture detection logic (swipe, point, open palm)
- [ ] 02-03: Three.js scene setup, section navigation via gestures

### Phase 3: Content & UI
**Goal**: All portfolio content displayed with polished, minimalist UI
**Depends on**: Phase 2
**Plans**: 3 plans

Plans:
- [ ] 03-01: About, Experience, Projects sections with content from resume
- [ ] 03-02: Skills, Education, Contact sections, resume PDF download
- [ ] 03-03: Gesture tutorial overlay, fallback keyboard/mouse navigation

### Phase 4: Polish & Deploy
**Goal**: Production-ready site deployed to AWS
**Depends on**: Phase 3
**Plans**: 2 plans

Plans:
- [ ] 04-01: Final styling, cross-feature testing, performance optimization
- [ ] 04-02: AWS S3 + CloudFront deployment, verification
