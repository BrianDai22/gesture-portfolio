<task type="auto">
  <name>Task 1: Create gesture state tracker for hand position history</name>
  <files>src/js/state/gestureState.js</files>
  <action>
    Create gestureState.js module that:
    1. Maintains rolling buffer of last 10 palm positions (wrist landmark, index 0)
       - Each entry: { x, y, timestamp }
    2. Tracks finger extension states (which fingers are extended vs curled)
       - Use landmark distances: fingertip to MCP joint vs finger length
       - Extended = fingertip significantly above MCP (in y) or far from palm
    3. Calculates palm velocity (change in position over time)
    4. Detects hand "stability" (low velocity = stable, for point gesture)

    Export:
    - updateGestureState(landmarks) - call each frame
    - getPalmPosition() -> {x, y}
    - getPalmVelocity() -> {vx, vy}
    - getFingerStates() -> { thumb, index, middle, ring, pinky } (each: 'extended' | 'curled')
    - isHandStable() -> boolean

    Key landmark indices (MediaPipe):
    - Wrist: 0
    - Thumb tip: 4, Index tip: 8, Middle tip: 12, Ring tip: 16, Pinky tip: 20
    - Thumb MCP: 2, Index MCP: 5, Middle MCP: 9, Ring MCP: 13, Pinky MCP: 17

    Avoid: Don't overcomplicate finger detection - simple distance threshold is enough for v1.
  </action>
  <verify>
    - Palm position updates each frame
    - Finger states accurately reflect extended vs curled
    - Velocity calculation is smooth (no jitter)
    - Stability detection works (stable when hand still)
  </verify>
  <done>Gesture state tracks palm position, velocity, and finger states accurately</done>
</task>

<task type="auto">
  <name>Task 2: Implement gesture recognizers (swipe, point, palm)</name>
  <files>src/js/gestures/gestureRecognizer.js</files>
  <action>
    Create gestureRecognizer.js module that:

    1. SWIPE DETECTION:
       - Trigger: Palm velocity exceeds threshold (0.15 normalized units/frame) in X direction
       - Direction: vx > 0 = swipe right (go prev), vx < 0 = swipe left (go next)
       - Debounce: 500ms cooldown after each swipe to prevent rapid-fire
       - Require: At least 3 fingers extended (open hand swipe, not fist)

    2. POINT DETECTION:
       - Trigger: Only index finger extended, others curled, hand stable
       - Output: Index fingertip position (landmark 8) normalized to viewport
       - Use for: Highlighting items under cursor
       - No cooldown needed (continuous tracking)

    3. OPEN PALM (HOME) DETECTION:
       - Trigger: All 5 fingers extended, hand stable for 500ms
       - Debounce: 1000ms cooldown (prevent accidental triggers)
       - Use for: Return to home/overview section

    Export:
    - initGestureRecognizer() - set up state
    - processFrame(landmarks) - call each frame, returns detected gesture or null
    - Returns: { type: 'swipe-left'|'swipe-right'|'point'|'palm-home', data?: { x, y } }
    - onGesture(callback) - register listener for gesture events

    Avoid: Don't make thresholds too sensitive (causes false positives). Start conservative, tune in Phase 4.
  </action>
  <verify>
    - Swipe left/right detected with deliberate horizontal motion
    - Point detected when only index extended
    - Palm-home detected when all fingers spread and stable
    - No false positives during normal hand movement
    - Debounce prevents rapid repeated triggers
  </verify>
  <done>Gesture recognizer detects swipe, point, and palm-home gestures reliably</done>
</task>
