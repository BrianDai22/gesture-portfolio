<task type="auto">
  <name>Task 2: Initialize MediaPipe Hands with dominant hand preference</name>
  <files>src/js/core/handTracking.js, src/js/state/handState.js</files>
  <action>
    Create handTracking.js module that:
    1. Creates MediaPipe Hands instance using window.Hands (from CDN)
       - Config: maxNumHands: 1, modelComplexity: 1, minDetectionConfidence: 0.7, minTrackingConfidence: 0.5
    2. Creates Camera instance from window.Camera (MediaPipe camera_utils)
    3. Connects camera to Hands for frame processing
    4. On results: Extract 21 hand landmarks, handedness (Left/Right)
    5. Export: initHandTracking(videoElement) -> Promise, getHandLandmarks() -> landmarks|null

    Create handState.js module that:
    1. Stores current hand landmarks (21 points with x, y, z normalized 0-1)
    2. Stores dominant hand preference (default: 'Right', stored in localStorage)
    3. Ignores hands that don't match preference
    4. Export: setDominantHand(hand), getDominantHand(), updateLandmarks(landmarks), getLandmarks()

    Avoid: Don't process both hands - only track the dominant one to reduce complexity.
  </action>
  <verify>
    - Hands instance created successfully (no console errors)
    - Landmarks update in handState when hand is visible
    - Non-dominant hand is ignored
    - Preference persists in localStorage
  </verify>
  <done>MediaPipe Hands tracks dominant hand, landmarks accessible via handState</done>
</task>
