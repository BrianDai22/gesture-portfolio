<task type="auto">
  <name>Task 1: Set up Three.js scene with renderer, camera, and lighting</name>
  <files>src/js/scene/sceneManager.js</files>
  <action>
    Create sceneManager.js module that:

    1. RENDERER SETUP:
       - Create WebGLRenderer attached to #three-canvas
       - Enable alpha: true (transparent background to show camera behind)
       - Set pixelRatio to window.devicePixelRatio (max 2 for performance)
       - Handle window resize (update renderer size and camera aspect)

    2. CAMERA SETUP:
       - PerspectiveCamera: FOV 60, aspect from window, near 0.1, far 1000
       - Initial position: (0, 0, 5) looking at origin
       - Will animate position to navigate between sections

    3. LIGHTING:
       - AmbientLight: soft white (0xffffff, 0.4) for base illumination
       - DirectionalLight: from top-right (0xffffff, 0.6) for subtle shadows
       - Keep minimal - geometric style doesn't need complex lighting

    4. RENDER LOOP:
       - Use requestAnimationFrame
       - Call scene render each frame
       - Export hook for adding update callbacks (for animations)

    Export:
    - initScene() -> { scene, camera, renderer }
    - getScene(), getCamera()
    - onUpdate(callback) - register per-frame update function
    - startRenderLoop(), stopRenderLoop()

    Avoid: Don't add OrbitControls - navigation is gesture-controlled, not mouse.
  </action>
  <verify>

    - No WebGL errors in console
    - Resize handler works (canvas scales with window)
    - Render loop runs at ~60fps
  </verify>
